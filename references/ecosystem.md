# Reuse boundary

The local audit found the CS Nature Paper V4.1 registry and scripts available,
but no behavior-qualified external employee. The reusable shape is its
query→identity→retrieve→claim/audit evidence contract, experiment planner and
capability inventory. The new skill calls only read-only, allow-listed adapters;
it does not copy or alter V4.1.

The external audit retained fixed commits, licenses, raw HTTP responses and
negative results in the private audit workspace. OpenAlex, Crossref and arXiv
are thin public adapters; Semantic Scholar may return 429 and must remain a
provider error. STORM and BoTorch inform design only. AI-Scientist and v2 use a
custom license with disclosure and restricted uses, so their code is not
included. AlphaEvolve's checked GitHub REST path returned 404. Pyro, MLflow and
DVC are optional future dependencies and are not required for V1.0.

The PyPI negative regression uses the actual LastPyMile (2021) metadata and
No Snake Oil (2026) evidence. A same-version artifact difference alone cannot
be reported as a strong novel contribution.
